# Research_Agent
A research agent to understand and analyze various aspects generate the portfolio of a company 
The financial data for the company was collected through yahoo finance 
The summary of the company was collected through wikipedia both of them as API 
once we collect the data we use LLM model to summarize the data and generate the portfolio
we also get an excel format 
The tech stack is as follows:
frontend : react.js
backens: fastApi , python
API: yfinance , wikipedia
libraries:pandas and openpyxl
